# Independent review checklist

[OBSERVED] This checklist identifies work a reviewer can perform; unchecked
items are not reported as completed external review.

- [x] Publish the 100 original claims, required metadata and catalogue hash.
- [x] Preserve pre-experiment protocol and separate bookkeeping/follow-on revisions.
- [x] Supply twenty scoped prior-art notes, primary links and unresolved cells.
- [x] Compare against a strong same-assumption baseline, not only a slow oracle.
- [x] Use independent exact-rational geometry and a separate small-grid oracle.
- [x] Retain every tested input, both seeds, transformations and defective variants.
- [x] Retain examples refuting matrix-change, sensing-cost and context extrapolation.
- [x] Distinguish written mathematical proofs from compiled-code tests.
- [x] Continue into statistics/control without changing the original hypotheses.
- [x] Exclude default OS, ISO, FCA and service changes.
- [ ] Reproduce from a fresh checkout on an independent Linux machine.
- [ ] Review the entire proof and the geometry oracle independently.
- [ ] Inspect compiler/binary provenance rather than relying on local hashes alone.
- [ ] Conduct an exhaustive literature and patent/disclosure search.
- [ ] Resolve the implementation/patent cells explicitly marked UNVERIFIED.
- [ ] Establish a nontrivial equal-assumption separation before claiming novelty.
- [ ] Run an independent proof assistant or formal code-verification artifact.
- [ ] Demonstrate an actual new OS capability on hardware, if a future claim needs it.

[UNVERIFIED] No external researcher has completed the unchecked items. A passing
local verifier is not peer review. No runtime integration should proceed merely
because the experiment scripts print success.
