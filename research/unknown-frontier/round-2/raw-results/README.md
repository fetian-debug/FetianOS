# Evidence scope

The two `seed-*` directories retain separate executions of the same finite
channel experiment. Each contains 1,184 exhaustive cases and 1,000 seeded
propagation cases; repetitions do not enlarge the exhaustive state space.
`family-2090` is the separately registered H113 extension. `original-80-fixed-*`
contains thirty evidence groups, not eighty independent implementations.

The first original-80 harness failure and the first unplanned other-field run
remain available alongside their corrected, fresh-directory runs. See
`../review-corrections.md`. The trailing blank line in the failed source text
is intentionally preserved as historical evidence. Exact original source bytes
are in the binary source archives; ordinary text checkout line endings may vary.

`manifest.json` contains local, unsigned checksums. The release observation is
read-only GitHub asset metadata, not a fresh download or verification of ISO
bytes. No physical energy, quantum-device or operating-system experiment was
performed. None of these records establishes a new computing capability.
